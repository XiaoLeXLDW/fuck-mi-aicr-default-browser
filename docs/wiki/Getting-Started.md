# 快速开始

准备一台 Android 8.0 或更高版本的设备、可处理 HTTPS 的第三方浏览器，以及已启动的 Shizuku 或 Stellar。Android 版本满足安装要求并不保证 ROM 可用，先阅读[兼容范围](Compatibility.md)。服务已启动时，首次配置约 2 分钟。

## 安装与首次观察

1. 安装可信来源的**已签名** APK，并核对发布说明中的版本和校验值。未签名构建不能直接安装；覆盖安装需包名与签名相容，不要默认任意 APK 都能覆盖旧版。
2. 在权限管理器中启动服务，打开“岛外打开”，选择“自动（推荐）”；若要单独测试官方 Shizuku，先保持 Stellar 服务停止。
3. 在目标浏览器菜单选择应用，保留“观察模式”，点“开启接管”，按提示授权所选后端。
4. 确认状态包含 `服务版本：v0.3.1（协议 200）`、`服务代：30002` 与 UID/PID，再从真实超级岛/超级小爱入口触发公开测试网址。
5. 若出现“观察到可接管网址”，关闭观察模式并再次点“开启接管”；重复同一入口，检查所选浏览器实际显示了目标页面。

观察模式会继续打开小米浏览器，这是预期行为。“已打开”只表示系统启动命令返回成功，页面是否正确仍需目视确认。不要使用含登录令牌或私人搜索的链接作为公开反馈证据。

## 选择菜单

点击目标浏览器卡片可查看图标、名称、包名与选中标记；同名浏览器用包名区分。菜单选择会保存为草稿，刷新或重开可保留；**只有再次点“开启接管”才应用到服务目标**。取消、返回或点弹窗外部不改变原选择。

原目标卸载或禁用时，需重新选择；应用不会静默换成第一项。找不到候选项时先安装可处理 HTTPS 的浏览器，再点“刷新状态”。浏览器弹窗的大字体、折叠和 TalkBack 体验仍需当前版实机确认。

## 切换后端与停止

1. 点“停用并退出服务”，等待 `停止完成 [v0.3.1]` 及 Binder 死亡确认。
2. 确认后端选择器恢复可操作，再切换后端；若选官方 Shizuku，停止 Stellar 后再开启。
3. 不再需要接管时保持停用。重开应用应维持已确认的停止状态。

只关页面或从最近任务划掉不会自动停止 UserService。停止未完成时先读[故障排查](Troubleshooting.md)，不要把消失的界面当成服务已退出。
