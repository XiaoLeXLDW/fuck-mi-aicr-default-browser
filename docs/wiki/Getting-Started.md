# 快速开始

准备一台 Android 8.0 或更高版本的设备、可通用处理 HTTP 与 HTTPS 的第三方浏览器，以及已启动的 Shizuku 或 Stellar。Android 版本满足安装要求并不保证 ROM 可用，先阅读[兼容范围](Compatibility.md)。服务已启动时，首次配置约 2 分钟；首次配对另留 5–10 分钟。

## 官方来源与权限服务准备

| 需要安装的内容 | 来源与说明 |
| --- | --- |
| 岛外打开 | [v0.3.3 Pre-release](https://github.com/XiaoLeXLDW/fuck-mi-aicr-default-browser/releases/tag/v0.3.3)；选择 universal APK 并核对同名 SHA-256 文件，当前版本仍待手机验收 |
| 官方 Shizuku | [官方下载页](https://shizuku.rikka.app/zh-hans/download/)与[用户手册](https://shizuku.rikka.app/zh-hans/guide/setup/)；不要从不明网盘下载改版 |
| Stellar | [上游项目](https://github.com/roro2239/Stellar)与[上游 Releases](https://github.com/roro2239/Stellar/releases)；本应用页面称其为“兼容服务（原生 API）” |

Shizuku 在 Android 11 及以上可按官方手册通过无线调试配对启动；较旧系统的无 Root 方式需
电脑 ADB，已有 Root 的设备也可按管理器指引启动。ADB 启动通常需在手机重启后重新执行，
配对成功不等于服务已启动。Stellar 按其管理器内的启动指引操作，不把 Shizuku 的启动命令
直接当作 Stellar 命令。[启动方式依据 Shizuku 官方手册](https://shizuku.rikka.app/zh-hans/guide/setup/)。

先在所选管理器确认服务“运行中”，再回到本应用。要单独验证官方 Shizuku，先停用本应用会话，
再停止 Stellar；自动模式会优先使用可用的 Stellar 原生服务。

## 安装与首次观察

1. 安装可信来源的**已签名** APK，并核对发布说明中的版本和校验值。未签名构建不能直接安装；覆盖安装需包名与签名相容，不要默认任意 APK 都能覆盖旧版。
2. 打开“岛外打开”，选择“自动（推荐）”或明确的后端；“兼容服务（原生 API）”对应 Stellar。
3. 选择目标浏览器，保留“观察模式”，点“开启接管”。在所选管理器的权限提示中允许“岛外打开”；
   Stellar 原生路径申请 `stellar` 基础权限，不需要为本应用额外开启跟随启动或无障碍。
4. 确认状态显示的版本、协议、服务代与已安装 APK 一致（见下表），并有 UID/PID；从真实超级岛/超级小爱入口触发公开测试网址。
5. 若出现“观察到可接管网址”，关闭观察模式并再次点“开启接管”；重复同一入口，检查所选浏览器实际显示了目标页面。

观察模式会继续打开小米浏览器，这是预期行为。“已打开”只表示系统启动命令返回成功，页面是否正确仍需目视确认。不要使用含登录令牌或私人搜索的链接作为公开反馈证据。

| 所装版本 | 业务协议 / 服务代 | 验证边界 |
| --- | --- | --- |
| v0.3.3（code 10） | 200 / 30004 | 本版 Shizuku、Stellar、冷启动与异常恢复仍待手机验收 |

若未弹窗或此前拒绝授权，在**当前选中的管理器**的应用授权列表中检查“岛外打开”，再回应用
刷新并重试；不会自动换另一个后端绕过拒绝。本应用不会替你设置系统默认浏览器，也不会接管 WebView。

## 选择菜单

点击目标浏览器卡片可查看图标、名称、包名与选中标记；同名浏览器用包名区分。菜单选择会保存为草稿，刷新或重开可保留；**只有再次点“开启接管”才应用到服务目标**。取消、返回或点弹窗外部不改变原选择。

原目标卸载或禁用时，需重新选择；应用不会静默换成第一项。找不到候选项时先安装声明了通用 HTTP 与 HTTPS 入口的浏览器，再点“刷新状态”；受域名、路径或 MIME 限制的入口不会作为浏览器候选。浏览器弹窗的大字体、折叠和 TalkBack 体验仍需当前版实机确认。

## 切换后端与停止

1. 点“停用并退出服务”，等待 `停止完成 [所装版本]` 及“已确认 UserService Binder 死亡”。
2. 确认后端选择器恢复可操作，再切换后端；若选官方 Shizuku，停止 Stellar 后再开启。
3. 不再需要接管时保持停用。重开应用应维持已确认的停止状态。

只关页面或从最近任务划掉不会自动停止 UserService。停止未完成时先读[故障排查](Troubleshooting.md)，不要把消失的界面当成服务已退出。
