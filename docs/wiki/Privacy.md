# 隐私说明

本页面向 v0.3.4。应用没有账号、分析 SDK 或上传功能，Manifest 未声明 `INTERNET`。UserService 使用管理器提供的 shell/root 身份，目标浏览器会访问网址；这些进程仍可能联网。

| 数据 | 当前用途与留存 |
| --- | --- |
| 浏览器名称、图标、包名 | 同时查询通用 HTTP/HTTPS 处理能力以生成本机候选菜单；保存所选包名，不上传应用清单 |
| 完整 HTTP/HTTPS 网址与目标包 | `RedirectDispatcher` 的有界去重表按配置代/目标/网址存储；队列至多 8 个等待任务，另有 1 个活动任务；`AmProcessLauncher` 与 `am start -d` 参数使用完整网址 |
| 最近事件 | 内存中一条状态，正常网址事件在 UI 只显示域名；不建立浏览历史数据库 |
| 配置 | 私有 SharedPreferences 保存目标、菜单草稿、模式、启用意图、后端归属和 Stellar verification token |

1.5 秒是成功任务的去重窗口，不是删除期限。排队/执行中的任务占用去重项；失败释放该项，
成功项由后续提交清理过期项或按容量淘汰，不按定时器自动删除。停用/配置变化/关闭调度器会清空
队列和去重表，活动任务收到取消标记；参数引用可能保留到清理和运行时回收，已提交系统的启动无法撤回。

`am` 合并输出持续读取，解析器暂存每行至多 192 字符进行错误判定，不保存原始输出文件或直接
显示进程异常消息。正常网址事件显示域名，域名本身也可能敏感；其他权限/连接/Controller 错误
仍可能包含敏感信息。系统日志、浏览器历史、进程诊断和 ADB 导出可能含完整 URL 或令牌。

配置存于私有 `redirector` SharedPreferences；随机 `stellar_verification_token` 用于服务
身份校验，不是账号或遥测 ID。管理器返回的原生 token、Binder、连接回调保存在进程内存。
完整持久化字段见[完整隐私说明](../PRIVACY.md)。

应用未声明存储、无障碍服务或 VPN 权限，也不读取网页正文或浏览器 Cookie。`allowBackup=false` 不覆盖设备厂商和用户自行制作的备份。

## 反馈与清除

1. 用 `https://example.com/` 等公开测试网址复现，避免个人链接和登录参数。
2. 分享前检查截图、日志和终端输出，删除账号、设备序列号、无线调试地址、完整私人 URL 与 token。
3. 停用时点“停用并退出服务”并等到 Binder 死亡确认。随后清除应用数据或卸载可重置配置，但不会删除浏览器历史与自行导出的日志。

仓库的 `scripts/verify-stop.ps1` 会安装并操作应用、启动/停止会话；`-SkipInstall` 可跳过安装。
页面转储写入设备 `/sdcard/codex-redirector-<随机 GUID>.xml`，每次使用独立文件名。
退出时仅尝试删除本次转储；ADB 断线、脚本被强制终止或删除失败可能留下文件。
它不是只读脚本。分享转储与终端输出前检查敏感信息；处理残留时只删除确认属于本次运行的文件。

更多恢复步骤见[故障排查](Troubleshooting.md)。
