# 岛外打开 v0.3.2 · Universal APK

实验版本，最低 Android 8.0（API 26），包名 `dev.codex.mibrowserredirector`，`versionCode 9`。
下载入口：[v0.3.2 Pre-release](https://github.com/XiaoLeXLDW/fuck-mi-aicr-default-browser/releases/tag/v0.3.2)。

## 本版修复

- 浏览器筛选要求同时提供通用 HTTP 与 HTTPS 入口，排除只处理特定域名、路径或文件类型的应用。
- 停服使用独立执行通道及总截止时间；超时报告“未确认”，旧调用结束前禁止重新开启。
- 停用或切换配置后，旧的待执行跳转任务失效；启动失败允许立即重试。
- 完善子进程取消、超时、输出和资源清理，以及页面 RPC 超时、旧回调隔离和 Shizuku tag 归属处理。

## 安装与升级

附件为 `MiBrowserRedirector-v0.3.2-universal.apk` 和同名 `.sha256`。沿用 v0.3.1 的历史测试证书，
版本号递增，同包名、同签名的安装可覆盖升级。升级前先在旧版中停用服务并等待停止完成。
通用 APK 无需选择 CPU 架构；这不代表所有 Android ROM 都已兼容。

安装后启动 Shizuku 或 Stellar 并授权，先观察网址捕获，再开启实际接管。源码归档与第三方
许可证随版本 tag 提供；APK 内含项目 MIT、Shizuku MIT、Apache-2.0、MPL-2.0 和第三方声明。

## 验证边界

核心单元测试覆盖浏览器筛选、停止、任务调度、子进程和会话归属等路径；本地构建记录见
[构建证据](../BUILD_EVIDENCE.md)，具体修复与测试范围见[修复记录](../FIX_REVIEW_0.3.2.md)。
最终发布附件的大小、SHA-256、证书指纹和构建提交记录在 GitHub Release 正文中。

当前版的实际浏览器筛选、Shizuku / Stellar 授权、跳转与停服、页面重建和超时恢复仍待真机
验收。模拟进程与核心单测不等于完整 UI 或 ROM 测试，因此继续标记 Pre-release。
仅处理发往小米浏览器的可解析网页启动；不支持 WebView，目标启动失败仍不自动回退。
