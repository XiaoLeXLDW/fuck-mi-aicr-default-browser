## 已知限制

本版尚未完成手机验收，不保证所有 HyperOS 机型及 Shizuku / Stellar 环境兼容。
不修改系统默认浏览器，不处理 WebView；目标浏览器启动失败不自动回退。
接管使用全局 Activity Controller，应避免同时运行其他控制器工具。
