# v0.3.1 · 岛外打开（Pre-release 草稿）

这是一份尚未发布的版本说明。源码已实现官方 Shizuku 与 Stellar 原生后端；当前版本实机矩阵
仍待完成。发布前填写下方产物信息，并同步当前测试结果。

## 本版内容

- 浏览器图标单选弹窗，显示名称、包名和系统默认标记。
- 选择草稿与运行目标分开，取消/刷新/重连不自动改动正在运行的目标。
- 保留双后端、会话来源固定、停服 Binder 死亡确认与 `72dp` 顶距。
- 补充中文文档与 Wiki、MIT 及第三方许可证、Wrapper 与静态检查工作流。

## 安装与使用

安装附件中的已签名 APK，启动 Shizuku 或 Stellar 并授权。先保持观察模式确认可捕获网页，
再关闭观察模式并点击“开启接管”。退出时点“停用并退出服务”并等待确认。
只允许签名兼容的覆盖安装；不要直接用未签名 CI 产物安装。

## 验证与限制

本地静态构建检查见[构建证据](../BUILD_EVIDENCE.md)。当前版官方 Shizuku、Stellar、两者同时
运行以及菜单视觉/大字体/TalkBack 均未取得本轮实机通过结果。历史 v0.2.0 Stellar 实机成功
不代表 v0.3.1 双后端已验证。

仅处理 `com.android.browser` 的可解析网页启动；WebView 不在范围。使用全局 Activity Controller，
可能被 ROM 限制或其他控制器覆盖。任务入队后阻止原启动，后续目标浏览器启动失败不会自动回退。
