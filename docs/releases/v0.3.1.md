# 岛外打开 v0.3.1 · Universal APK

已于 2026-09-05 发布 [GitHub Pre-release](https://github.com/XiaoLeXLDW/fuck-mi-aicr-default-browser/releases/tag/v0.3.1)，附件已回下载核对 SHA-256。

面向小米 / HyperOS 的实验版本，通过 Shizuku 或 Stellar 将交给小米浏览器的网页转到指定浏览器。

## 下载与安装

下载附件 `MiBrowserRedirector-v0.3.1-universal.apk`，最低 Android 8.0（API 26）。这是可独立安装的通用 APK，不含原生库，无需选择 CPU 架构；通用打包不代表所有 ROM 都已兼容。

本次沿用历史本地测试证书签名，可与同签名、同包名的历史包保持升级兼容。此证书仍为测试证书，本版本标记 **Pre-release**；未来改用正式证书时需另行处理升级关系。

启动 Shizuku 或 Stellar 并授权，先用观察模式确认网址捕获，再关闭观察模式并开启接管。退出时点击“停用并退出服务”，等待停止完成。

## 本版内容

- 浏览器图标单选菜单，显示名称、包名和系统默认标记。
- 选择草稿与运行目标分开，点击“开启接管”后应用。
- 官方 Shizuku API 与 Stellar 原生双后端，服务会话固定使用创建它的后端。
- 中文文档与 Wiki、MIT 及第三方许可证、Gradle Wrapper 和 CI 检查。

## 验证与限制

本次 Release 构建成功；28 项单测通过，0 失败 / 错误 / 跳过；Lint 为 0 错误、9 警告。APK v2 签名、ZIP 对齐、包名 / 版本、双后端 Manifest、无 ABI 限制和五份内置许可文本均已核验。单测使用 Gradle 对未变化输入的既有通过结果。
