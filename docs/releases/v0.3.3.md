# 岛外打开 v0.3.3 · Universal APK

实验性预发布版本，最低 Android 8.0（API 26）；包名 `dev.codex.mibrowserredirector`，`versionCode 10`。
[下载 v0.3.3](https://github.com/XiaoLeXLDW/fuck-mi-aicr-default-browser/releases/tag/v0.3.3)。

## 更新内容

- 更新黑白猫耳图标与浏览器跳出徽章，增加 Android 自适应、单色主题图标和仓库展示素材。
- 原生会话固定来源管理器、token 与页面租约，改善晚到回调、验证拒绝和停止失败后的清理。
- 协议拒绝或验证超时后禁止业务调用，停止清理使用独立执行通道和截止时间。
- 修复断连后状态读取卡住、停止期间晚到回调覆盖清理对象等页面生命周期问题。
- 保留顶部 72dp 最小安全距，增加系统栏/刘海安全区与可访问性支持，完善离线回归和文档。

## 安装与升级

下载附件 `MiBrowserRedirector-v0.3.3-universal.apk` 与同名 `.sha256`。
沿用既有测试证书，同包名、同签名的旧版满足覆盖升级条件；升级前先在旧版点“停用并退出服务”，
等待停止完成。安装后启动 Shizuku 或 Stellar 并授权，先观察网址捕获，再开启实际接管。
无需选择 CPU 架构；通用安装包不代表所有 ROM 已验证兼容。

## 验证与限制

本地 Debug / Release 构建成功，每个变体的 JUnit 报告 119 项通过，原生源码 harness 14 项通过，
共 133 项不同 Java 用例；增量任务可复用已有结果。另有 30 项离线脚本回归本次执行通过。
两种 Lint 均为 0 错误、12 警告。APK 版本、签名、ZIP 对齐、Universal 属性与许可证已核验。
完整记录见 [构建证据](https://github.com/XiaoLeXLDW/fuck-mi-aicr-default-browser/blob/591339e07ea6740e5e0e76c7162ef73eadc2ec07/docs/BUILD_EVIDENCE.md)，
修复约束见 [v0.3.3 修复说明](https://github.com/XiaoLeXLDW/fuck-mi-aicr-default-browser/blob/v0.3.3/docs/FIX_REVIEW_0.3.3.md)。

本版尚未做手机验收：官方 Shizuku / Stellar 的实际授权、跳转、停服、重开、异常恢复，以及
HyperOS 图标和页面显示均待确认。仅处理发往小米浏览器的可解析网页启动，不处理 WebView；
目标浏览器异步启动失败不自动回退。继续标记 **Pre-release**。
