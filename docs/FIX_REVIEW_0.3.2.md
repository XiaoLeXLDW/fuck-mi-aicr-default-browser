# v0.3.2 修复记录

输入：用户提供的 v0.3.1 浏览器菜单截图，以及针对源码 `8962682` 的“检查项目问题”报告。
报告里的模拟复现不是本机/真机验证，修复阶段重新构建可运行的回归用例。该阶段未自动推送或发布；后续发布状态见[版本说明](releases/v0.3.2.md)。

## 浏览器误筛选

截图确认淘宝、网易云音乐、WPS 等非浏览器被列入菜单。原代码只要求匹配某个 HTTPS URL，
只排除自身和 `com.android.browser`，没有验证通用浏览器能力。

现在分别查询 HTTP 和 HTTPS，使用 [GET_RESOLVED_FILTER](https://developer.android.com/reference/android/content/pm/PackageManager#GET_RESOLVED_FILTER)
读取实际匹配的声明；两类入口都必须具备 VIEW/BROWSABLE/DEFAULT，且没有 host、路径、
scheme-specific-part 或 MIME 限制。检查使用公开 [IntentFilter](https://developer.android.com/reference/android/content/IntentFilter)
接口，不依赖应用名关键字、包名白名单或隐藏的 ResolveInfo 字段。系统默认标记不能绕过筛选。
同一浏览器可以把 HTTP 与 HTTPS 分开声明；按包名聚合后再取交集。

快速回归：`scripts/test-browser-filter.ps1`。10 项测试在旧接纳条件下 4 项失败，修改条件后
10 项通过。它验证真实代码使用的判定函数，输入是明确标注的模拟解析元数据，不是假装读到了
手机上各应用的 Manifest。若应用主动声明为无限制浏览器仍可能被列入；声明不标准的浏览器
也可能漏收。截图中实际 14 项是否被正确筛掉，仍需手机回归，不能仅凭测试宣称全部消失。

## 停服与页面协调

停止任务不再排在读取状态/启用的单线程队列后；两个进程级有界执行通道避免页面重建无限
创建线程。快速回归 `scripts/test-service-lanes.ps1` 在共享通道时两项失败，独立后两项通过。

UserService 已连接时，停止的 4 秒总预算覆盖 disable、管理器 remove、存活检测与 destroy，
不是只计最后的轮询。同步 Binder 调用不能保证被 interrupt 中断：超时只恢复界面并保留服务
归属，不能伪报停止完成；旧调用实际结束前禁止重新启用或重复发出破坏性清理。

点击停止后的连接、排队与清理共享 12 秒截止时间；已连接清理最多取其中剩余的 4 秒。
页面主动发起的管理器查询、请求授权、绑定和解绑走后台；查询/绑定的 8 秒监督在调用入队前注册，
不需要等待同步调用返回才能开始计时。授权弹窗等待用户选择不受发送请求的 8 秒限制。

收到 Binder 即保存清理身份，不必先等待协议 RPC。身份验证、启用和读取状态增加 8 秒页面
监督；旧结果通过 operation epoch / token 隔离。连接超时后才到达的首个 Binder，只在原后端、
没有更新绑定且仍由当前页面拥有操作时保留用于清理，不能重新启用；总截止时间耗尽则保留供
手动重试，不发起新清理调用。后端未运行时退出“启动中”，恢复操作入口。权限管理器交互、
页面重建与 ROM 行为仍需实机验收；页面协同路径目前只有源码复核和 Android 编译证据。

Shizuku API 13.1.5 的 `unbindUserService(..., false)` 会清空整个稳定 tag 的回调，
并不是只移除传入的那个连接。适配器使用跨页面的 tag 租约：旧会话只清理自己的回调引用，
不得解绑新会话。绑定、解绑和移除在同一非等待准入门下执行；与正在进行的调用冲突时拒绝，
不额外阻塞停止线程。旧 SDK 回调项可能保留至下一次安全的 tag 清理或 Binder 死亡。

## 跳转任务与子进程

停用、更换目标和观察模式变更须使旧配置的待执行任务失效；去重必须区分等待/运行、成功与
失败，失败后允许立即重试。已提交给系统的浏览器打开操作不能撤回，不承诺关闭已打开的页面。
回调保持异步，不在 `activityStarting()` 中等待外部命令。

子进程启动、等待、取消和输出处理必须有界并关闭流；错误信息不得包含原网址的路径、查询
参数或 token。相关单测使用假进程覆盖异常路径，不等于证明真实 ROM 的所有 am 行为。

## 未扩大的功能边界

1. 原启动已阻止后若目标启动失败，仍不自动回退小米浏览器；允许重新点击重试。
2. 全局 Activity Controller 无独占所有权保证，不与其他 Controller 工具并用。
3. 启动仍使用当前用户，工作资料/系统分身不在兼容承诺内。
